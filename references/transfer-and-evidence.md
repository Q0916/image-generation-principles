# 근거·가설·적용 범위

## 이 스킬의 지위

IGP는 “가설단계에서 이미지 모델에 생성협조를 요구한” 데서 출발한 제작 지침이다. 제작 경험과 미술 작법을 토대로 선택을 설명하고 이미지 모델에 구현을 요청한다. 사용자의 좋은 실사용 결과 피드백은 유지하되, 모델 내부 기제를 증명하거나 개별 문구의 품질 향상률·보편적 재현성을 검증했다고 확대하지 않는다.

**현재 확인 범위(2026-10-21): 긍정적인 실사용 피드백은 오로지 Codex에서 ima2로 이미지를 생성한 경로에서만 확인했다.** ima2는 여기서 실행 도구를 가리키며 정확한 내부 백엔드 모델 버전·전처리까지 검증했다는 뜻은 아니다. 공홈 Library에 파일을 추가하고 실제로 읽게 해 지침으로 적용할 수 있으며, Codex에서는 IGP와 ima2를 함께 사용할 수 있다. 이 사용 가능성과 모델별 효과 검증은 다르다. 다른 제공자에 대한 효과나 무작위 대조 실험으로 입증된 인과 효과는 주장하지 않는다.

| 층위 | 확인하거나 판단하는 것 | 그 사실만으로 확정하지 않는 것 |
| --- | --- | --- |
| 작법 자료 | 저자가 설명한 원리·목적·조건 | 특정 생성 모델에서 같은 효과가 자동 발생함 |
| 제작자의 가설 | 이번 요구에 어떤 시각 수단이 맞는지와 WHY | 유일한 정답·확정된 작동 기제 |
| 실제 전달 | 도구에 넣은 본문·첨부·옵션 중 관찰 가능한 것 | 숨은 재작성·전처리 뒤의 입력 동일성 |
| 생성 결과 | 실제 보이는 형태·표정·빛·질감·정보 | 한 문구가 그 결과를 인과적으로 만들었음 |
| 사용자 선택 | 사용자가 그 후보를 좋게 보고 선택함 | 모든 지시 구현·재현성·일반 이론의 확정 |

이 구분은 작업 판단에 쓰며 모든 이미지에 검증 보고서를 붙이라는 절차가 아니다. 내부 입력이 보이지 않을 때만 그 확인 한계를 필요한 지점에 적는다.

## 실제 제출 기록을 여는 방법

1. 사용자가 선택한 원본 또는 실제 사용 기록에서 결과와 요청 ID를 찾는다. 로컬 ima2 생성 이력에서 본문, 첨부와 결과를 열거나 작업 폴더에 보존된 유효 요청 목록과 제출 기록으로 돌아간다.
2. ima2 아카이브 형식이라면 아래 명령으로 제출 당시 첨부 순서, 보존 본문과 서버 기록, 생성 원본 경로를 함께 확인할 수 있다. 기록이 비어 있으면 보고값은 `unverified`다.

   ```text
   python scripts/read_ima2_example.py PATH_TO_EFFECTIVE_JOBS_JSONL EXACT_JOB_ID
   ```

3. 해당 첨부 원본과 결과를 실제로 열어 비교한다. 이어지는 CG는 각 요청의 기준 이미지가 어느 앞선 컷에서 왔는지도 본다. 개별 이미지가 모델에 들어간 사실은 제출 기록에서, 채택 여부는 사용자 선택이나 사용 기록에서 확인한다. 이 도구는 로컬 기록을 읽으며 생성 요청을 보내지 않는다.

## 먼저 참고할 성공 사례

같은 프로젝트에서 사람이 채택했거나 실제 사용한 그림의 원본과 입력을 우선한다. 새 작업의 핵심 문제를 기준으로 가까운 사례를 고른다.

| 만들어야 할 것 | 먼저 찾을 사례와 볼 지점 | 다음 입력에 옮길 것 |
| --- | --- | --- |
| 한 장면을 그리는 이벤트 CG와 연속 차분 | 채택 CG의 실제 본문, 얼굴·의상·구도 참조, 전후 컷과 실제 화면. 장소와 인물이 같은 광원 아래 있는지, 누구의 눈으로 어떤 순간을 보는지 확인한다. | 한 박자의 앞뒤 이유와 관객이 먼저 볼 표정·접촉을 전달한다. 공식 얼굴과 현재 복식, 구도와 장소 자료에 각각 역할을 준다. 후속 컷은 기준 CG와 달라지는 연기를 함께 전달한다. |
| 같은 인물의 몸짓이나 표정을 바꾸는 스탠딩 | 채택 얼굴의 원본 확대, 의상·자세 참조와 얼굴·손을 가린 사본, 붙여서 본 인게임 비교. 얼굴과 동세 중 어떤 요소를 사용자가 살렸는지 확인한다. | 얼굴·복식·동작을 각각 근거에 연결한다. 인물이 왜 그렇게 반응하는지 적고, 상황이 살아날 세부 연기는 모델에 맡긴다. |
| 단독 일러스트·키비주얼·포스터 | 같은 감상 크기 또는 게시처의 채택본. 무엇이 먼저 읽히며 거기까지 어떤 명암·실루엣·에지가 도왔는지 확인한다. | 실제 보일 크기에서 완성할 핵심 구조와 큰 형태를 본문 앞으로 가져오고, 주변의 마감은 그 주목 관계에 맞춰 조절한다. |

이벤트 CG의 첫 컷에는 공식 얼굴과 채택 복식에 더해, 두 사람이 누워 가까이 눈을 맞추는 기존 장면을 구도 참조 이미지로 실제 첨부했다. 결과에서는 한 인물의 얼굴과 어깨가 관찰자의 눈높이에서 읽혔다. 이어지는 차분마다 기존 구도가 담긴 기준 CG를 실제로 넣어 자세·시선·빛을 이어받았고, 앞뒤 대사와 지문 원문으로 표정이 바뀌는 이유와 그릴 한 박자를 전달했다. 별도의 만화 사례에서는 한 컷의 연기를 위해 해당 컷의 원문과 작품 전체 흐름을 함께 제출했다. 원문 분량은 모델이 인물 관계, 행동의 동기와 전후 변화를 읽는 데 필요한 만큼 잡는다. 같은 묶음에서도 별개의 효과까지 합친 변형은 보류됐다. 여기서 가져올 경험은 **감정이 바뀌는 한 박자를 실제 입력으로 전달하고, 필요한 외형과 관찰 관계를 알맞은 참조로 유지하는 것**이다. 특정 문구나 도구의 효과를 모든 상황에 확대할 근거는 없다.

## 공개판에 남긴 기능과 WHY

- **세 축과 직접적인 매력:** 창작자·관객·상업적 볼거리를 함께 판단한다. 예쁘게·귀엽게·야하게·잘 팔리게라는 주문을 서사적 정당화 요구로 바꾸지 않는다. 성별 이름만으로 매력 공식을 고정하지 않는다.
- **문맥을 보존하는 전달:** 행동·관계·감정·정보차·전후 이유가 바뀌면 그림 해석도 바뀔 수 있다. 장문이라는 이유로 버리지 않고 구조화한다. 불필요한 운영 이력은 실제 이미지 입력에서 덜어낸다.
- **체스터턴과 작법:** 기존 규칙이 어떤 기능을 지키고 어떤 실패를 막는지 이해한 뒤 적용하거나 예외를 고른다. 미술 지식은 제작 전에 선택을 바꾸는 데 쓰고, 완성 뒤 용어를 붙이는 데서 끝내지 않는다.
- **의미 잠금과 구현 자유:** 의미·정체성·핵심 관계를 고정하고 같은 뜻을 살리는 구체적 표현은 모델이 풀 수 있게 한다. 중요한 정확한 손짓이나 카메라가 요청의 핵심이면 그것도 잠근다.
- **참조·복잡성·배경의 역할:** 정체성과 구도·스타일을 구별하고, 어디에 시선과 표현을 쓸지 판단한다. 흰 배경·얼굴 확대·낮은 밀도를 보편법칙으로 만들지 않는다.
- **사용 크기와 마감 우선순위:** 인물 전신 이미지의 비교에서, 뒷머리의 큰 구조를 완성 기준에 포함하고 남는 여력을 마지막 마감에 쓰도록 요청한 그림이 작게 보았을 때 더 나았다는 제작자 피드백을 받았다. 이 방법은 무엇이 그 크기에서 먼저 읽혀야 하는지 정하는 작업 가설이다. 관찰은 당시 도구 경로와 소수 후보에 한정되며 생성 모델 내부의 토큰 배분, 작화 순서, 다른 매체의 재현성을 측정한 결과는 아니다.
- **몸짓과 얼굴을 함께 보존한 전신:** 기존 전신을 그대로 참조한 후보에선 몸짓을 개선해도 눈매가 약해졌다. 원하는 몸짓을 만든 후보의 얼굴과 손만 가린 사본, 앞서 고른 얼굴 확대, 공식 화풍을 함께 전달한 후보에 긍정적인 피드백을 받았다. 이 비교에서는 참조 구성과 작화 문장이 함께 바뀌었다. 자세가 몸에 작용하는 힘, 이미 고른 눈매, 손짓의 의미를 각각 회수하는 사례로 쓴다.
- **실제 픽셀과 비율:** 전신 시험에서 세로로 긴 캔버스가 총 픽셀 수를 거의 유지하면서 인물에 더 많은 픽셀을 배정한 사례가 있었다. 같은 비율에서 요청 치수만 더 올렸을 때 실제 반환 치수는 같았다. 실루엣과 여백을 각 작품에 맞추고 반환 파일의 치수를 읽는다.
- **원본과 선택 보존:** 새 구도와 원본 편집을 구별한다. 사용자 선택을 존중하고 관련 부분을 개선하며 성공을 주장할 범위를 실제 관찰에 맞춘다.

## 실험과 매체 경계

파편 셀채색 문서는 요청된 경우만 쓰는 미해결 스타일 연구다. 실험 비교 조건은 후보 장수나 비용을 자동 승인하지 않는다. 작품별 컷 수·원고 크기·식자·흰 띠·고정 밀도·합본 방식은 그 작품의 계약이 소유한다. 이런 선택의 기능을 이해하는 것과 단일 그림에 수치를 이식하는 것은 다르다.

## 공개판의 계보

v1.2의 공통 이미지 원칙 → v2.1의 직접적인 미적 목표·작법 조사·체스터턴 보강 → v2.2의 독립 공개 스킬·기본 단독 이미지 적용으로 이어졌다. 개인 프로젝트에서 나온 제작 경험을 범용 작화 판단으로 정리했으며, 원고·개인 세션·과거 원본 이미지·인증·설치 영수증·로컬 실행 하네스는 배포하지 않는다. 문서의 출처·조건·교훈은 본문과 참고자료에서 확인할 수 있고, 비공개 저장소 접근 없이 적용할 수 있다.

작법 출처와 해석 구분은 [작법 조사·체스터턴](illustration-craft-and-chesterton.md), 문맥 보존과 상세 이유는 [상세 원칙](foundations-and-rationale.md)에 있다. 이 패키지는 이미지 생성 도구나 도구 사용 허가 자체를 제공하지 않는다.
